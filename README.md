# proxy-sub — автообновляемая подписка на бесплатные прокси

Публичный набор проверенных узлов **VLESS** и **Hysteria2**, обновляется автоматически раз в сутки.

## Что внутри

| Файл | Для чего |
|---|---|
| `v2ray.txt` | base64-подписка: v2rayNG, Hiddify, NekoBox, Streisand |
| `clash.yaml` | mihomo / Clash Verge / ClashX — с группой `AUTO` (url-test) |
| `nodes.txt` | plain-список, по одной ссылке в строке |

## Как подключить

**Hiddify / v2rayNG / NekoBox** — «Добавить профиль → Из подписки» и вставить:

```
https://raw.githubusercontent.com/st0rer/proxy-sub/main/v2ray.txt
```

**Clash Verge / mihomo** — «Profiles → New → URL»:

```
https://raw.githubusercontent.com/st0rer/proxy-sub/main/clash.yaml
```

Клиент сам перечитывает подписку по расписанию (в Hiddify: Настройки → Обновление подписки).

## Как это обновляется

Ежедневно в 04:30 UTC: сбор ~8 000 публичных конфигов → TCP-отбор → реальная проверка трафика
через mihomo → отсев узлов, идущих через VPN-туннель → публикация только живых.
Обычно остаётся 20–40 узлов из тысяч: публичные ноды мрут за часы.

## Важно

- Узлы **публичные, бесплатные и чужие** — не гоняй через них банки, аккаунты и что-то чувствительное.
- Провайдер узла видит твой трафик. Для приватности нужен свой сервер, а не публичная нода.
- Файлы перезаписываются автоматически, руками править смысла нет.

## Мобильный профиль

Отдельная подписка для мобильного интернета: узлы проверяются **из сети
оператора**, а не из дома — там другой DPI, и часть домашних узлов недоступна.

```
https://raw.githubusercontent.com/st0rer/proxy-sub/main/yota.txt        # base64
https://raw.githubusercontent.com/st0rer/proxy-sub/main/yota-nodes.txt  # plain
https://raw.githubusercontent.com/st0rer/proxy-sub/main/yota-clash.yaml # clash
```

## Как это устроено

Конвейер открыт: [st0rer/proxy-sub-builder](https://github.com/st0rer/proxy-sub-builder) —
сбор из GitHub-списков, сайтов-каталогов и публичных телеграм-каналов; проверка
тем же ядром, что у клиента, тремя ступенями и с контролем реального трафика;
публикация с чтением назад и откатом на предыдущий список.

## Оговорки

Узлы — публичные, чужие. Ничего не гарантируется: часть умрёт через часы. Это
нормально — подписка пересобирается несколько раз в сутки. Только личное
использование.
